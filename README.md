# Melty Mobile

Mobile-first game library aggregator built with Expo React Native.

## Run locally
npm install && npx expo start

## Features
- Unified searchable collection with platform filters
- Discover catalog and manual game additions
- Account connection UI for Steam, Microsoft/Xbox, Epic
- Dark purple mobile interface

## Integrations
Account sign-in and ownership imports require provider registrations and a secure backend. See docs/INTEGRATIONS.md. The UI does not fake authenticated accounts.

## Android
GitHub Actions exports an Android bundle artifact. A signed/installable APK requires EAS Build or Android Gradle/signing configuration.
